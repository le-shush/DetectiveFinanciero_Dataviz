# Detective financiero — comparativo de industrias

Reporte interactivo (Plotly, sin dependencias de red) que compara promedios de O&G, Biotech, Tecnología y Pharma
y las cuatro empresas por identificar (A–D). Tres vistas: Industrias (completa/reducida), Empresas A–D, Empresas vs industrias (valores o desviación %). Modo oscuro.

- Regenerar: ver `CLAUDE.md` (sección "Regenerar todo").
- Publicar: GitHub Pages → Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
